# Referências de Templates

Esta pesquisa reúne referências visuais encontradas na Figma Community para auxiliar no desenvolvimento do EduTrack AI. Os templates serão utilizados apenas como inspiração para estrutura, organização e componentes da interface.

## 1. Vision UI Dashboard React – MUI Dashboard

Link: https://www.figma.com/design/RgeNRM2REyLbbsFoPxfYEP/Vision-UI-Dashboard-React---MUI-Dashboard--Free-Version---Community-?node-id=1601-6435&p=f&t=kYFk6tftbN2HLIag-0

### Por que é útil
- Referência para organização de dashboards.
- Inspiração para cards e apresentação de informações.
- Possibilidade de observar menus, navegação e componentes reutilizáveis.
- Pode ajudar na definição da estrutura visual do painel do EduTrack AI.

## Observação

Os templates foram utilizados somente como referências visuais e de estrutura. O objetivo não é copiar os projetos, mas identificar ideias que possam ser adaptadas ao EduTrack AI.
