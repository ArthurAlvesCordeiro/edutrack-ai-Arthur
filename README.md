# EduTrack AI

**EduTrack AI** is an academic tracking application that enables students and educators to manage subjects, tasks, and generate professional performance reports in PDF format.

## Vision Overview
- Provide a unified experience across **FlutterFlow** (front‑end), **Xano** (backend‑as‑a‑service), and a **FastAPI** service (hosted on Render) for PDF generation.
- All data is scoped per authenticated user; no cross‑user data leakage.
- PDFs are generated on‑demand via the `/generate-pdf` endpoint and can be stored as a Xano file resource or Base64 fallback.

## Architecture Diagram
```
FlutterFlow UI  <--->  Xano API (REST)  <--->  FastAPI /generate-pdf (Render)
```
- **FlutterFlow**: UI layer, calls Xano endpoints.
- **Xano**: Stores user data (subjects, tasks, reports) and provides authentication (`X‑API‑Key`).
- **FastAPI**: Stateless service that receives a JSON payload, builds a PDF using ReportLab, and returns binary PDF.

## Getting Started
### Prerequisites
- Python 3.12
- Docker (for containerised FastAPI service)
- `SEARCH_API_KEY` environment variable set to a secret value (used by FastAPI for auth).

### Running the FastAPI Service Locally
```powershell
# Install dependencies
python -m pip install -r services/search_api/requirements.txt

# Export API key (example)
$env:SEARCH_API_KEY="test-secret"

# Start the FastAPI app
uvicorn services.search_api.main:app --reload --port 8000
```
### Running Tests
```powershell
# PDF generator unit tests
python -m unittest scripts.test_generate_performance_pdf -v

# FastAPI endpoint tests
python -m unittest discover -s services/search_api -p "test_*.py" -v
```
All tests should pass (`0 failures`).
